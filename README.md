
# Django User Management System

A web-based user management system built with Django. The project provides user authentication, user registration, profile management, role-based access, and CRUD operations for managing users.

## Features

* User registration
* User login and logout
* Secure password handling using Django authentication
* User dashboard with statistics
* User profile management
* User list
* Search users by username
* Filter users by role
* Pagination for user lists
* Create new users
* Update user information
* Delete users
* Activate and deactivate users
* Admin, Manager, and Staff roles
* Email, first name, and last name management
* Phone number field
* Avatar/profile image support
* Success and error messages
* Login-protected user management pages

## Technologies Used

* Python
* Django
* HTML
* CSS
* SQLite

## Project Structure

The project consists of a Django project named `user_management` and an application named `accounts`.

The `accounts` application handles user authentication, registration, user management, forms, models, views, URL routing, and templates.

## Purpose

This project was built to demonstrate practical Django backend development skills, including:

* User authentication
* Custom user models
* Database integration
* Forms and validation
* URL routing
* Views
* CRUD operations
* Role-based access
* Search and filtering
* Pagination
* Template handling
