# Django User Management System

A web-based user management system built with Django. The project provides user authentication, user registration, profile information management, role management, and complete CRUD operations for managing users.

## Features

* User registration
* User login and logout
* Secure password handling using Django authentication
* User dashboard with user statistics
* User list
* Search users by username
* Filter users by role
* Pagination for user lists
* Create new users
* Update user information
* Delete users
* Activate and deactivate users
* Admin, Manager, and Staff roles
* Email, first name, and last name management
* Phone number field
* Avatar/profile image support
* Success and error messages
* Login-protected user management pages

## Technologies Used

* Python
* Django
* HTML
* SQLite

## Project Structure

The project consists of a Django project named `user_management` and an application named `accounts`.

The `accounts` application handles user authentication, registration, user management, forms, models, views, and templates.

## Purpose

This project was built to demonstrate practical Django backend development skills, including authentication, custom user models, database models, forms, URL routing, views, templates, CRUD operations, search, filtering, and pagination.
