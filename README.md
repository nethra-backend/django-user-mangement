# Django User Management System

A web-based user management system built with Django. The project provides user registration, login, authentication, profile management, and role-based access control.

## Features

* User registration
* User login and logout
* Secure password authentication
* User profile management
* Dashboard for authenticated users
* Role-based access control
* Form validation and error handling
* Success and error messages
* SQLite database

## Technologies Used

* Python
* Django
* HTML
* CSS
* SQLite

## Project Structure

The project is organized into a Django project named `user_management` and an application named `accounts`.

The `accounts` application handles user-related functionality such as registration, authentication, profiles, dashboards, and access control.

## Purpose

This project was developed to demonstrate practical backend development skills using Django, including authentication, database integration, URL routing, views, forms, templates, and user access management.
